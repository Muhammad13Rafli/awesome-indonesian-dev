# Contributing to Awesome Indonesian Developer Resources

Terima kasih mau kontribusi! 🎉

## Cara Menambahkan Resource

### Via Pull Request (Recommended)

1. Fork repo ini
2. Edit `README.md` — tambahkan resource baru di kategori yang sesuai
3. Format: `| [Nama](url) | Deskripsi singkat |`
4. Kirim Pull Request dengan judul: `Add: [nama resource]`

### Via Issue

Kalo males fork, buka [Issue](https://github.com/Muhammad13Rafli/awesome-indonesian-dev/issues/new) dengan template:
- **Nama**: 
- **URL**: 
- **Kategori**: 
- **Deskripsi**: 

## Aturan

- Resource harus **berkaitan dengan developer Indonesia**
- Ga boang spam atau self-promotion berlebihan
- Link harus aktif dan valid
- Deskripsi singkat dan jelas (maks 1 baris)
- Urutkan alphabetikal dalam kategori

## Kategori yang Tersedia

- API & Payment Gateway
- Belajar Programming
- Bootcamp & Course
- Komunitas Developer
- Dataset Indonesia
- Open Source Lokal
- Tools & Hosting Gratis
- Job Board
- Conference & Event
- Blog & Channel YouTube

Mau nambah kategori baru? Buka Issue dulu biar kita diskusi.

## Questions?

Buka [Issue](https://github.com/Muhammad13Rafli/awesome-indonesian-dev/issues) aja!
